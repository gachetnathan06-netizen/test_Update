# Compagnon (BOB) — iOS

App iPhone native (SwiftUI, iOS 16+). BOB vit uniquement dans l'app : skins, humeurs, accessoires, caresses.

## Obtenir l'app (sans Mac)
1. Pousse ce dossier sur un dépôt GitHub. Onglet Actions > "Build IPA" > télécharge `Compagnon-IPA` (Compagnon.ipa, non signé).
2. Sur Windows : installe **Sideloadly** (ou AltStore), branche l'iPhone, glisse le .ipa, connecte-toi avec ton Apple ID gratuit. L'app dure 7 jours puis se réinstalle de la même façon.

## Avec un Mac
`brew install xcodegen && xcodegen generate`, ouvre `Compagnon.xcodeproj`, choisis ton iPhone, Run.
